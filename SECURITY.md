# Security Policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch. Older releases may not receive security updates.

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected vulnerability.

Until a dedicated security contact is configured, report security issues privately to the repository owner through [GitHub](https://github.com/hitesh-reddy-k). Include:

- A clear description of the vulnerability.
- Steps to reproduce or a minimal proof of concept.
- The affected commit, route, component, or configuration.
- The potential impact.
- Any suggested mitigation.

Please allow reasonable time for investigation before publicly disclosing a vulnerability. Do not include passwords, access tokens, private keys, or personal data in a report.

## Scope notes

PacificBoard depends on PacificDB Community Edition. Issues in PacificDB itself should also be reported through the PacificDB project's official security process when applicable.
